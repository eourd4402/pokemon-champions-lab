Pokémon Champions Stat Lab v16 PWA

구성
- index.html              앱 본체
- manifest.webmanifest    설치형 웹앱 설정
- sw.js                   자동 업데이트 / 캐시 / 오프라인 fallback
- icons/                  설치 아이콘

중요
1. file:/// 로 index.html을 더블클릭하면 기존 계산기는 사용할 수 있지만
   PWA 설치와 서비스워커 자동 업데이트는 작동하지 않습니다.
2. 이 폴더 전체를 HTTPS 웹주소에 올리면 설치형 PWA가 됩니다.
   GitHub Pages / Vercel / Netlify 등 정적 호스팅이면 충분합니다.
3. manifest의 start_url/scope와 서비스워커 경로가 모두 상대경로(./)라
   GitHub Pages의 프로젝트 하위 경로에서도 동작하도록 구성했습니다.
4. 앱을 열 때마다 서비스워커가 새 버전을 확인하며,
   새 서비스워커가 활성화되면 페이지가 한 번 자동 새로고침되어 최신 버전을 적용합니다.
5. 샘플 보관함 데이터는 기존 localStorage 키를 그대로 사용합니다.
   같은 웹주소에서 업데이트하면 저장한 샘플/파티는 코드 업데이트와 별개로 유지됩니다.
6. 현재 포켓몬/기술/도구 데이터 일부는 외부 소스에서 불러옵니다.
   최초 온라인 로드 후에는 서비스워커 runtime cache가 가능한 데이터를 재사용하지만,
   완전 오프라인 단일 패키지는 아직 아닙니다.

업데이트 방법
- 앞으로 새 index.html/sw.js/manifest 등을 같은 웹주소에 덮어 올립니다.
- sw.js의 APP_VERSION을 새 값으로 변경하면 기존 앱이 새 서비스워커를 감지합니다.
- 사용자는 별도 설치파일을 다시 받을 필요가 없습니다.


모바일 사용
- Android Chrome: 사이트 접속 후 상단의 '앱 설치' 버튼 또는 Chrome 메뉴의 '앱 설치'를 사용합니다.
- iPhone/iPad Safari: 사이트 접속 → 공유 버튼 → '홈 화면에 추가'를 선택합니다.
- 설치 후에는 주소창 없는 독립 앱 창으로 실행됩니다.
- PC와 모바일은 같은 index.html/계산 로직을 사용하고 CSS만 화면 크기에 따라 달라집니다.
  따라서 같은 웹주소에 새 버전을 올리면 PC 웹과 모바일 설치 앱이 함께 업데이트됩니다.

v16.1 모바일 레이아웃
- 현재 샘플: 모바일 상단 접이식 카드
- 화면 하단 고정 메뉴: 샘플 / 보관함 / 내구 / 공격 / 속도
- 상세 계산 입력: 모바일에서는 기본 1열 배치
- 샘플 보관함: 2열 카드(아주 작은 화면에서는 1열)
- 타입 상성표: 가로 스크롤
- 입력칸/버튼: 터치용 크기 확대


v16.2 모바일 레이아웃
- 화면 상단에 현재 샘플 요약을 항상 고정 표시
- 요약 내용: 포켓몬 / 성격 / 특성 / 도구 / H-A-B-C-D-S / 사용 P
- 상단 '편집' 버튼으로 샘플 편집 화면으로 바로 이동
- 하단 메뉴는 펼치기 기능이 아니라 실제 화면 탭 전환
- 모바일에서는 샘플 / 보관함 / 내구 / 공격 / 속도 중 선택한 하나만 표시
- 분석의 펼치기/접기 제목은 모바일에서 숨김
- PC 버전은 기존 좌측 고정 샘플 + 우측 접이식 분석 구조 유지


v16.3 모바일 상단 샘플
- 상단 고정 현재 샘플에 기술 1~4를 작은 한 줄 칩으로 추가
- 기술명이 길면 말줄임 처리
- 매우 작은 화면에서는 기술 칩을 가로 스크롤 가능
- 기술 선택을 바꾸면 상단 요약도 즉시 갱신


v16.4 모바일 상단 기술 표시
- 상단 고정 현재 샘플의 기술 4개를 2열 × 2행으로 표시
- 네 기술이 항상 동시에 보임
- 긴 기술명은 각 칸 안에서 말줄임 처리


v16.5 모바일 빠른 수정
- 상단 고정 '현재 샘플'의 수정 버튼은 더 이상 샘플 탭으로 이동하지 않음
- 현재 분석 화면 위에서 빠른 수정 패널을 열고 닫음
- 빠른 수정 가능: 성격 / 특성 / 지닌 도구 / H-A-B-C-D-S 능력 P / 기술 1~4
- 변경값은 기존 샘플 입력값에 직접 동기화되고 계산에 즉시 반영
- 포켓몬/폼 등 전체 설정이 필요할 때만 '포켓몬 · 폼 등 전체 편집'으로 샘플 탭 이동


v16.6 목적별 분석 화면 분리
- 내구 분석 2차 탭
  1) 공격 버티기: 상대 공격 설정 + 실제 피해 + 1/2/3타 생존 + 최소 H/B/D 역산
  2) 내 포켓몬 내구: 물리/특수 내구지수 + 투자 효율 + HP 4N/8N/16N
- 공격 분석 2차 탭
  1) 상대 상세 계산: 실제 상대 세팅 + 피해/타수 + 최소 A/C 역산 + 상세 전투 조건
  2) 내구 기준선: H0/H2/H32/풀내구 기준선 비교만 표시
- 내 공격 설정은 두 공격 분석 모드에서 공통으로 항상 표시
- 마지막으로 선택한 2차 탭 상태를 브라우저에 기억
- PC와 모바일 모두 동일한 목적별 분리 구조 적용


v16.7 분석 화면 순서 수정
- 공격 분석:
  내 포켓몬 설정 -> 상대 내구 분석 선택 -> 선택한 상세 계산/내구 기준선 순서로 재배치
- 상대 상세 계산 내용이 선택창 위에 나타나던 구조 수정
- 모바일에서 공격 분석 2차 선택창은 공통 내 포켓몬 설정 바로 아래에 표시
- 내구 분석:
  '내 포켓몬 내구'를 '공격 버티기'보다 앞에 배치
  새 버전의 기본 화면도 '내 포켓몬 내구'로 변경

  · Pokémon Showdown 기술 데이터
  · Pokémon Showdown 도구 데이터

v17.1 업데이트 판정 방식 수정
- 기존 문제:
  서비스워커 waiting 상태만 보고 최신 여부를 판단하여
  서버에 새 버전이 있어도 구버전 화면에서 '최신 버전 사용 중'으로 오판할 수 있었음
- 새 방식:
  저장소 루트의 app-version.json을 GitHub Pages에서 cache:no-store로 직접 읽음
  현재 실행 중 버전과 서버 최신 버전을 실제 문자열로 비교
- 서버 최신 버전과 현재 버전이 다르면 PC/모바일 모두
  '새 버전 vXX 있음' + 업데이트 버튼 표시
- 버전 확인에 실패하면 '최신 버전 사용 중'이라고 표시하지 않고
  '최신 버전 확인 실패'라고 명확하게 표시
- 업데이트 버튼:
  1) service worker update() 강제 확인
  2) waiting worker가 있으면 SKIP_WAITING
  3) waiting worker가 잡히지 않아도 서버 버전이 더 최신이면 cache-busting 네트워크 재접속
- 앱 재포커스/화면 복귀 시에도 최신 버전 재확인
- 15분마다 백그라운드 최신 버전 확인

- 모바일 최초 접속 시 현재 샘플 요약을 무조건 화면 최상단에 고정하지 않음
- 페이지 상단에서는 제목 / 버전 / 업데이트 상태 / 기기별 설치 안내가 전부 먼저 보임
- 현재 샘플 요약은 원래 위치에서 보이며, 사용자가 아래로 스크롤해 샘플 영역을 지나간 뒤에만 상단 고정
- 고정 전환 시 placeholder로 레이아웃 점프 방지
- 빠른 수정창 높이가 변해도 고정 영역 높이를 자동 재계산
- PC 레이아웃은 기존 방식 유지
- 기존 설치 UX, 업데이트, 메가진화, 분산 데미지, 기술 검색, 파티 보관 및 오프라인 캐시 유지


v17.6 Android 설치 버튼 반응 수정
- beforeinstallprompt 제공 시: 버튼 클릭 → 실제 설치창
- 설치 프롬프트 미제공 시: 버튼 클릭 → 반드시 설치 방법 팝업 표시
- Android에서 프롬프트가 없을 때 버튼 문구를 '설치 방법'으로 변경
- 삼성 인터넷 감지 시 삼성 인터넷용 안내 표시
- 일반 Android 브라우저는 ⋮ 메뉴 → 앱 설치/홈 화면에 추가 안내
- iPhone/iPad는 Safari 공유 → 홈 화면에 추가 안내
- PC도 설치 프롬프트가 없으면 주소창/브라우저 메뉴 설치 방법 팝업
- 기존 v17.5 모바일 상단 가림 수정 및 모든 계산 기능 유지


v17.7 모바일 레이아웃 / 설치 동선 수정
- 모바일 상단 topbar의 중복 버전/업데이트 배지를 숨김
- 버전/최신상태/업데이트 버튼은 기존 위치인 현재 샘플 요약 하단에 유지
- 페이지 최상단 여백을 늘려 제목과 설치 영역을 충분히 볼 수 있게 함
- 설치 영역과 샘플 요약 사이 여백 확대
- 샘플 요약은 처음에는 일반 흐름에 있고, 아래로 스크롤해 지나간 뒤에만 상단 고정

Android 설치
- Chrome이 beforeinstallprompt를 제공하는 경우: 웹 버튼 → 실제 설치창
- 카카오톡 인앱 브라우저 감지 시: '설치 방법'이 아니라 'Chrome에서 열기' 표시
- 'Chrome에서 열기'는 Android intent로 현재 GitHub Pages 주소를 Chrome에 전달
- 인앱 브라우저가 intent를 차단하면 설치 안내 팝업을 자동 표시
- 보안상 실제 PWA 설치의 최종 '설치' 확인은 Android/Chrome이 요구하며 웹이 생략할 수 없음


v17.8 모바일 설치 영역 항상 표시
- 기존 문제:
  모바일에서 설치 안내를 한 번 닫으면 localStorage에 숨김 상태가 남아
  새 버전에서도 설치 버튼이 보이지 않을 수 있었음
- Android/iPhone에서는 기존 숨김 상태를 무시하고 페이지 로드시 제거
- 모바일에서는 설치 영역의 X 닫기 버튼을 숨김
- 앱이 실제 standalone/PWA로 실행 중일 때만 설치 영역을 숨김
- 카카오톡 인앱 브라우저: 제목 아래에 'Chrome에서 열기' 버튼 상시 표시
- Android Chrome에서 beforeinstallprompt가 제공되면 '지금 설치'로 실제 설치창 실행
- 기존 모바일 샘플/버전 위치와 계산 기능 유지


v17.9 설치 안내 PC 전용
- 설치/바로가기 안내 영역은 PC에서만 표시
- Android/iPhone 등 모바일에서는 설치 안내 영역 완전 숨김
- 모바일에서 beforeinstallprompt가 발생해도 웹 내부 설치 버튼은 표시하지 않음
- 모바일 PWA 자체 기능, 오프라인 캐시, 업데이트, 샘플/분석 기능은 그대로 유지
- PC에서는 기존 '앱으로 설치/설치 방법' 동작 유지


v18.0 메가진화 연결 안정화 + 검색 도우미
- 메가폼은 megaFormsByBase의 기본 포켓몬 소유관계를 reverse map으로 검증
- 현재 포켓몬과 관계없는 메가폼 값이 남아 있으면 기본폼으로 자동 복구
- 메가스톤 자동 장착도 현재 기본 포켓몬의 megaStone 매핑만 허용
- 포켓몬 검색 필터에서 임의로 한카리아스로 fallback하던 로직 제거
- 검색 결과가 현재 선택 포켓몬을 포함하지 않을 때는 첫 검색 결과를 사용하고 폼 목록 재생성
- 포켓몬/기술/도구 검색창에 실시간 검색 도우미 추가
- 한글/영문 부분검색, 앞글자 우선 정렬, 최대 10개 후보 표시
- 후보 클릭/터치로 즉시 선택
- PC 키보드 ↑↓/Enter/Escape 지원
- 모바일 빠른 수정 기술 검색에도 검색 도우미 적용
